# Практическая работа № 18. Исключения и работа с ними в Java

Проект IntelliJ IDEA с 4 легкими заданиями по теме `try`, `catch`, `finally`, `throw`, `throws`:

1. **Task1.java** — деление на ноль (`2.0 / 0.0` и `2 / 0`) и перехват `ArithmeticException`.
2. **Task2.java** — ввод строки, перевод в число (`Integer.parseInt`), несколько блоков `catch` (`NumberFormatException`, `ArithmeticException`, `Exception`) и блок `finally`.
3. **Task3.java** — генерация `NullPointerException` через `throw` и обработка ошибки без аварийного завершения.
4. **Task4.java** — проброс проверяемого `Exception` с помощью `throws` и цикл повторного ввода непустого ключа.

Можно запускать как общий `Main.java` (меню), так и отдельно каждый `Task1`–`Task4`.
