# Java Практики 18–21

Учебные проекты IntelliJ IDEA по курсу Java: четыре практические работы, каждая в своей папке.

| Папка | Тема | Задания |
|---|---|---|
| [Praktika18](./Praktika18) | Исключения: `try`, `catch`, `finally`, `throw`, `throws` | Task1–Task4 |
| [Praktika19](./Praktika19) | Свои исключения и работа с файлами | Task1–Task4 |
| [Praktika20](./Praktika20) | Обобщения (generics) | Task1–Task4 |
| [Praktika21](./Praktika21) | Обобщения и коллекции | Task1–Task4 |

## Как запускать

Каждая папка — отдельный проект IntelliJ IDEA. Откройте её через **File → Open** и запустите:

- `Main.java` — меню со всеми заданиями сразу;
- либо любую отдельную задачу `Task1`–`Task4`.

Подробности по каждой работе — в `README.md` внутри соответствующей папки.

## Состав репозитория

- `src/` — исходный код;
- `.idea/` — настройки проекта и run-конфигурации;
- каталог `out/` (скомпилированные `.class`) в репозиторий не попадает — он в `.gitignore`.
