# Практическая работа № 19. Создание пользовательских исключений

Проект IntelliJ IDEA с 4 легкими заданиями по созданию собственных исключений:

1. **Task1.java** — проверяемое исключение `BadFileNameException` (`extends Exception`).
2. **Task2.java** — непроверяемое исключение `BadFileExtensionException` (`extends RuntimeException`).
3. **Task3.java** — онлайн-покупка: ввод ФИО и ИНН с исключением `InvalidInnException`.
4. **Task4.java** — сортировка студентов по среднему баллу и поиск по ФИО с `EmptyStringException` и `StudentNotFoundException`.

Можно запускать как общий `Main.java` (меню), так и отдельно каждый `Task1`–`Task4`.
