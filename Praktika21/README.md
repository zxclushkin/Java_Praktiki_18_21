# Практическая работа № 21. Стирание типов в Java

Проект IntelliJ IDEA с 4 легкими заданиями по теме стирания типов и обобщенных методов:

1. **Task1.java** — обобщенный метод `arrayToList(E[] array)` для конвертации массива строк/чисел в список.
2. **Task2.java** — класс `AnyTypeArray<E>`, хранящий массив любых типов данных (`Integer`, `Long`, `String`).
3. **Task3.java** — получение любого элемента массива по индексу (`AnyTypeArray.get` и `getElementByIndex`).
4. **Task4.java** — сохранение содержимого каталога в `List<String>` и вывод первых 5 элементов на экран.

Можно запускать как общий `Main.java` (меню), так и отдельно каждый `Task1`–`Task4`.
